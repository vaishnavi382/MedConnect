# Doctor Module

## Role
Doctor Module Developer

## Responsibilities

The Doctor Module provides doctors with a dedicated interface to manage
their profile, availability and appointments.

## Main Features

### 1. Doctor Dashboard
- Display doctor information
- Show today's appointments
- Display daily patient queue
- Show appointment summary

### 2. Doctor Profile
- Doctor name
- Specialization
- Room/Cabin number
- Bio
- Visiting days
- OPD timings

### 3. Doctor Availability
- Configure visiting days
- Configure working hours
- Manage available consultation slots
- Define slot duration

### 4. Appointment Management
- View booked appointments
- View patient details
- Update appointment status
- Mark appointment as completed or cancelled
- Add brief medical remarks
